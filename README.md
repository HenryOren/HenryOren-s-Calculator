# ABOUT THE PROGRAM
## WHAT IS IT
This a calculator that is use Python for Windows by HenryOren. The version is alpha 0.1. Because this program that is use Python to edit, so you must install Python in your computer.

**INSTALL PYTHON**\
1.[Click to access Python official website](www.python.org/downloads/)\
2.press the button "Download Python 3.xx" to install the installer\
3.run the installer\
4.install Python\

**RUN THE PROGRAM**\
1.Press "WIN + R"\
2.Input "cmd" in the input box\
3.Run command: ```py ./main.py```

## HOW CAN IT DO
The program that is use function ```eval()``` to calculate. The program support 0~9 and +-*/.
